# 画面卡片规范（PIL 白底学术风）

参考模板：`../scripts/make_cards.py`。所有卡片 1920×1080，输出到 `cards/`。

## 配色

| 用途 | RGB | 说明 |
|---|---|---|
| 纯白底 | `(255,255,255)` | 所有正式卡默认 |
| 正文黑 | `(20,20,25)` | 标题/要点 |
| 次级灰 | `(60,60,70)` | 描述文字 |
| 蓝强调 | `(0,90,200)` | 方案/主流程/下划线 |
| 红强调 | `(200,40,40)` | 痛点/风险 |
| 绿强调 | `(0,140,90)` | 成功/结果 |
| 深蓝横幅 | `(0,63,124)` | 片头横幅 |
| 深色渐变 | `(14,14,22)→(48,48,66)` | 预告卡/实测背景 |

**单卡只用一种强调色**。红蓝混用会稀释语义。

## 字体

```
/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc
/usr/share/fonts/opentype/noto/NotoSansCJK-Black.ttc
```
- 标题 56px Bold，要点 42px Bold，正文 38–40px Regular，片头大字 100–120px Black。
- 全部 `anchor` 显式指定（`"ma"` / `"mm"`），避免基线猜测。

## 版式规则

1. 标题左上对齐 `(140, 110)`，标题下方 5px 强调色下划线，下划线长度用 `d.textlength(标题)` 精确匹配。
2. 要点列表：左侧红色/蓝色圆点（直径 30px，`d.ellipse`），圆点后要点名 42px Bold，描述 40px Regular 灰字；行间距 120px。
3. 文字防溢出：长文用 `wrap_text`（按 `draw.textlength` 逐字换行）。
4. 片头卡：深蓝横幅 `(0,63,124)` 自 y=300 到 y=820，横幅内主标题 120px Black、副题 54px Bold、课题组 44px Regular，全白字。
5. 结束卡：白底居中大字 96px Black + 下方 40px 次级灰小字；也可按用户要求简化为只留"谢谢"两字（120px Black 居中，白底），无副题。

## 预告卡（先预告再放实测视频）

- 左右对称深色渐变底（按 `x` 逐列画，边缘深 `(14,14,22)`、中心浅 `(48,48,66)`）。
- 上下两条装饰线（宽 690→1230，高 2px，绿色 `(0,150,90)`）。
- 居中大字 100px Black 白色，下方副字 42px 浅灰。
- **防重叠铁律**：装饰线 y 坐标与任何文字边界保持 ≥40px。用字号推算文字高（如 100px 字 ≈ ±50px 范围，中心 y=465 → 覆盖 415–515），再定装饰线位置（如上线 y=320、下线 y=660）。
- 副字若居中，`anchor="mm"` 且中心 y 与下线相距 ≥40px。

## 实测段背景卡

左右对称深色渐变（边缘深、中心浅），中间留白给等比居中的竖屏视频。**不要模糊背景**——模糊显脏，渐变干净且不抢注意力。
