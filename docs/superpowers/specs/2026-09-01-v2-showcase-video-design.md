# V2 科技成果展示版设计

## 目标

将现有116秒专属RAG对比视频重新剪辑为约72秒的科技成果展示成片。测试版允许删除、压缩和重排镜头，优先展示视频制作效果，同时确保所有结论来自项目权威复盘和真实录屏。

工作仅存在于 `v2-enhance-showcase` 支线，不修改 GitHub `main`，不覆盖任何原始视频。

## 视觉与叙事定位

- 风格：正式科技成果展示，深蓝底、青绿数据、橙色章节强调。
- 节奏：开头快速建立价值，中段用真实画面证明，结尾集中呈现量化结果。
- 原则：一屏只讲一个结论；动态效果克制；不使用会抖动的低分辨率 `zoompan`。
- 字幕：底部居中，复用旁白文案，避开页面原始信息。
- 音频：中文男声、舒缓低音量BGM，结尾淡出。

## 旁白

1. 两本教材，一千八百一十七个知识块，能否让专业回答更准确、更可溯源？
2. 驭远智擎构建发动机与电动汽车专属RAG，完成检索、重排，再注入最相关证据。
3. 在燃烧过程题中，关键点命中率从百分之四十三提升到百分之八十六。
4. 其余三题保持满分，同时补齐教材出处，让回答可以核验。
5. 四题平均命中率由百分之八十五点八，提升到百分之九十六点五。
6. 随后用直问、口语化、设问三种表达，测试同一知识点的泛化稳定性。
7. 发动机有效指标、电驱动系统特点、并联混合动力构型，换一种问法，RAG仍能稳定命中。
8. 九种问法平均命中率从百分之六十升到百分之八十九，波动从八十三个百分点收窄到二十九个百分点，九问引用全部可溯源。
9. 让专业回答更准确、更稳定，也让每个结论都有依据。

## 技术实现

- PIL生成5张1920×1080视觉卡：片头、方案、四题指标、泛化章节、终局指标、片尾（片尾与片头可复用构图但单独渲染）。
- 四题镜头从原116秒视频的4–36秒分段截取，每个8秒镜头压缩至4秒。
- 泛化镜头从 `viz_gen.mp4` 选取K1、K3、K4各6秒。
- 静态卡先Lanczos预放大到7680×4320，再做轻微平滑推进，避免整数像素抖动。
- 所有画面段先统一为24fps、1920×1080、yuv420p，再concat。
- edge-tts使用 `zh-CN-YunjianNeural`，按时间轴逐段生成；旁白不足段长时保留呼吸空间。
- 字幕从同一旁白文案生成ASS，PlayResY=1080，放在底部安全区。
- numpy确定性混音：人声按段落放置，BGM音量0.08，结尾3秒淡出。

## 验收标准

- 成片时长72秒，允许误差±0.10秒。
- 1920×1080、24fps、H.264 + AAC、44.1kHz双声道。
- 四题和三个泛化知识点均有真实画面证据。
- 所有指标与项目复盘一致，不展示被剔除的K2。
- 平滑推进无明显抖动；字幕不遮挡原页面重要内容。
- 各段人声响度一致，BGM不压人声，无削波。
- 交付前逐帧抽样、字幕带检查、ffprobe和volumedetect全部通过。
